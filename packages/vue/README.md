# `@mithtech-bengaluru/tonaldepth-vue`

Vue 3 adapters for the TonalDepth core package.

```ts
import { TdButton, TdCard, TdInput } from "@mithtech-bengaluru/tonaldepth-vue";
import "@mithtech-bengaluru/tonaldepth-vue/styles.css";
```

Initial P0 exports: TdButton, TdBadge, TdCard composition, TdInput, TdTextarea, and TdFormField. Nuxt consumes the same Vue package; there is no duplicate Nuxt component implementation.

This package is local and unpublished until its clean Vue and Nuxt consumer gates pass.
