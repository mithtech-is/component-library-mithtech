# `@mithtech-bengaluru/tonaldepth-core`

Private TonalDepth web foundation prerelease.

```css
@import "@mithtech-bengaluru/tonaldepth-core";
```

The default entry includes generated canonical variables and the preserved web 1.x `.td-*` compatibility stylesheet. Consumers may import `tokens.css` alone.

Font-family tokens are included, but font binaries are not packaged until Google Fonts license/provenance files are mapped to the audited binaries. The package makes no network font requests.
